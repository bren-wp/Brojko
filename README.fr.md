## Trois modes de jeu

- Classique 4×4 : le défi des 16 cases.
- Détente 5×5 : davantage d’espace pour tes combinaisons.
- Défi quotidien : de nouveaux objectifs avec un nombre limité de coups.

Fusionne les nombres identiques, gagne des étoiles, découvre les missions et les succès et suis tes records. Choisis un thème clair, sombre ou coloré et joue hors ligne. BROJKO propose 30 langues ; le français se choisit dans les paramètres.
