## 📸 Svi ekrani i pravi gameplay

Ovo su **stvarne snimke funkcionalne Android aplikacije** iz automatiziranih emulatorskih UI testova — nisu renderirane ilustracije, generirane slike niti dizajnerske makete. Galerija pokriva početne stranice, oba načina igre, aktivni dnevni gameplay, statistiku, teme, postavke, pomoć i potvrde.

Galerija koristi provjerene snimke iz izdanja **v1.12.211**. Svih 28 fotografija dolazi iz stvarnog Android prikaza, a trajne poveznice ostaju dostupne i dok se priprema novo izdanje. [Pogledaj najnovije izdanje](https://github.com/bren-wp/Brojko/releases/latest) za aktualnu aplikaciju i njezine snimke.
